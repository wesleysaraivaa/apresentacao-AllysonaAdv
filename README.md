# Apresentação - Proposta de Presença Digital

Página interativa de apresentação da proposta de desenvolvimento de site institucional para escritório de advocacia.

## Visão Geral

Projeto focado em demonstrar a proposta de valor, o conceito visual, o escopo de trabalho e a versão demonstrativa desenvolvida para apresentação ao cliente.

## Tecnologias

- **React 19**
- **TanStack Router / TanStack Start**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React**
